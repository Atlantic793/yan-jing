# 言镜演示

摄像头看口型，只区分圆唇和展唇，并用一句话说明嘴唇该怎么动。演示案例只有「衣 / 鱼」。

## 技术栈

只用这一套：

- 浏览器里的 MediaPipe Face Landmarker，模型和 wasm 都在 `web/` 里，不访问外网
- 从面部关键点取嘴角和上下唇，用两眼距离归一化
- 先记下这个人的自然口型，再比较现在的嘴比自己更圆还是更宽
- 规则直接写出一句动作提示。没有标准口型库，没有相似度，没有按对错给的奖励
- `start.bat` 用 Python 标准库把页面开在本机。不需要安装额外的包

## 运行环境

- Windows 10 或 11
- Python 3.11 及以上（已在 3.13 上启动）
- Chrome 或 Edge
- 一台摄像头
- 不需要麦克风，不需要联网

## 启动

双击 `start.bat`。浏览器会打开演示页。不要直接双击 `index.html`。

弹出摄像头权限时选允许。然后按 `F` 或点「全屏」再投屏。

## 演示怎么走

1. 人对着镜头，表情放松，点「记下自然口型」，停大约两秒。
2. 点「衣」。嘴角明显向两边拉开。底部应出现「现在嘴唇是拉开的」。再把嘴收回自然状态，应变成「嘴唇再往两边拉开」。
3. 点「鱼」。嘴唇明显收圆、收小。底部应出现「现在嘴唇是圆的」。嘴还是扁的时候，应出现「嘴唇没圆起来」。
4. 同一个口型下来回切「衣」和「鱼」，句子会跟着目标变。这是要给评委看的一段。
5. 点「记一次练习」。次数加一，和刚才嘴唇圆不圆无关。

动作要做明显。轻轻动一下，句子可以仍停在自然口型附近。

界面预演（地址后面加 `?preview=1`）只用动画看版式。正式投屏不要打开它。

## 演示时不要主动说

- 不说舌位，不拿「鱼」和「乌」、「鱼」和「无」做对比
- 不说发音准不准，不说矫正、疗效
- 不说相似度、得分、通过、正确、错误
- 不说标准口型库
- 如果被问到「鱼」和「乌」：只回答「这个演示只看嘴唇圆不圆，舌位不在里面」，然后回到「衣 / 鱼」

## 界面上的提示

- 现在嘴唇是圆的
- 嘴唇还可以再圆一点
- 嘴唇没圆起来
- 现在嘴唇是拉开的
- 嘴角还可以再拉开一点
- 嘴唇太圆了，往两边拉开
- 嘴唇再往两边拉开

固定说明是「不打分，不评价发音」。
